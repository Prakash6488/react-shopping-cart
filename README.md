# React Shopping Cart

A React-based Shopping Cart application that demonstrates shopping cart functionality using React Context API.

## Features

- Display products
- Add products to the shopping cart
- Manage cart items
- Share cart data using React Context API
- Update cart details
- Remove products from the cart

## Tech Stack

- React.js
- JavaScript
- HTML
- CSS
- React Context API

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Prakash6488/react-shopping-cart.git
```

2. Open the project folder:

```bash
cd react-shopping-cart
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in the terminal.
